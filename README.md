# Простой рофельный чекер актуальности ядра на Bash

Это мой почти что первый скрипт на Bash который просто проверяет версию ядра и сверяет её с актуальной на kernel.org

## Что в нём

1. Проверка ядра
2. Проверка ядра
3. da.✅️
4. А чо тут ещё сказать?

## Установка

1. Введи в терминале ``git clone https://github.com/kirieshka228-govno/kernelchecker.git && cd kernelchecker``
2. Запусти чекер командой ``./kernelchecker.sh``

## Если при запуске "Чо то не так пошло alo✔"

Если ты столкнулся с этой ошибкой то попробуй сделать это:

1. Проверь интернет (Скрипт юзает интернет чтобы получить версию ядра)
2. Проверь доступен ли kernel.org: Попробуй зайти на kernel.org в браузере и через команду curl

Если ничего не помогает то значит проблема в моём говнокоде а мне лень исправлять это da.✅️
